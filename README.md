## The entry

> We spent an hour in the meeting that should have been an email, and the only thing we emailed afterwards was the invite to the next one.

## How to run

```sh
python3 main.py
```

This writes the one-liner to `entry.txt` in the output directory
(default `/output`, or `$MAKEFUN_OUTPUT_DIR` when set).

## Gate

- The entry is exactly one line of UTF-8 text: **136 characters** (plus a
  trailing newline), within the competition gate of 1–200 characters.
- One joke, one line, about a meeting that should have been an email.
